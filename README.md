Códigos fonte das animações feitas em manim/python e o modelo 3d do plano cartesiano tátil  do projeto de iniciação cientifica

# Desenvolvimento de Animações Didáticas e Plano Cartesiano Tátil para o Ensino de Funções Polinomiais

Este repositório reúne os códigos, materiais gráficos e arquivos de modelagem tridimensional desenvolvidos no âmbito do projeto de Iniciação Científica (PIBIC), focado em matemática assistiva para estudantes com baixa visão.

---

## 📌 Sobre o Projeto

O objetivo principal desta pesquisa é desenvolver recursos educacionais acessíveis para o ensino de funções matemáticas (conceitos fundamentais, função afim e função quadrática), combinando:
1. **Animações Vetoriais Adaptadas:** Códigos desenvolvidos na linguagem Python utilizando a biblioteca `Manim` para criação de animações gráficas com contraste, escala e elementos visuais adequados para pessoas com baixa visão.
2. **Plano Cartesiano Tátil:** Arquivos de modelagem 3D projetados para fabricação de material concreto manipulável, servindo como apoio tátil ao aprendizado.

## 🛠️ Conteúdo do Repositório

* `/codigos`: Scripts em Python (`.py`) estruturados com a biblioteca Manim.
* `/modelagem_tatil`: Arquivos tridimensionais (`.stl` / `.obj`) para impressão 3D do plano cartesiano tátil.
* `/animacoes_exportadas`: Vídeos demonstrativos das animações finalizadas.
